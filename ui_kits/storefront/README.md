# Pantria Storefront — UI Kit

A pixel-fidelity recreation of the public ecommerce experience: sticky nav, hero, category tiles, featured products, product detail, cart, checkout, and order tracking — all wired as a click-thru prototype.

## Components

- `Nav.jsx` — sticky top nav with search, account, cart
- `MobileTabBar.jsx` — bottom tab bar (mobile only)
- `Hero.jsx` — promo hero with split layout
- `CategoryTiles.jsx` — 7-up category shortcuts
- `ProductCard.jsx` — square image, name, price, add button
- `ProductGrid.jsx` — responsive 2/3/4-up grid
- `PromoBanner.jsx` — accent-soft promo strip
- `Testimonial.jsx` — short review cards
- `DeliveryChecker.jsx` — barangay input + result
- `Footer.jsx` — links + contact
- `MessengerFab.jsx` — floating chat button
- `Cart.jsx` — drawer with line items
- `Checkout.jsx` — single-page checkout
- `OrderTracking.jsx` — timeline view

## Screens (in `index.html`)

1. Homepage
2. Shop (with filters)
3. Product detail
4. Cart drawer
5. Checkout
6. Order tracking

Use the top tab bar to navigate between screens.
