# Pantria Admin — UI Kit

Desktop dashboard for inventory, sales analytics, product/order/customer management, and promo management.

## Components

- `Sidebar.jsx` — left nav with sections (Dashboard, Products, Orders, Customers, Promos)
- `Topbar.jsx` — page header with search, notifications, user menu
- `StatCard.jsx` — metric tile (KPI + trend)
- `BarChart.jsx`, `LineChart.jsx` — pure-CSS charts (no library)
- `DataTable.jsx` — sortable table with selection + actions
- `LowStockList.jsx` — inventory alert panel
- `OrderRow.jsx`, `ProductRow.jsx` — table row variants

## Screens (in `index.html`)

1. Dashboard overview (KPIs, sales chart, low-stock alerts, recent orders)
